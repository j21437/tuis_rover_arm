# ESP32-S3 + TMC5160T Pro ステッピングモータ テストツール

ESP32-S3とBIGTREETECH TMC5160T Pro V1.0を使用し、減速機付きステッピングモータ（NEMA23）をPC上のGUIから操作するためのテストプログラムです。

出力軸を指定角度だけ回転させる動作と、A・Dキーによる手動ジョグ操作に対応しています。ファームウェアを書き込み済みのESP32を使用する場合、PC側でESP-IDFの導入やBuild・Flashを行う必要はありません。

## 1. 主な機能

- 相対回転角度指定：1～360°（整数、減速機の出力軸基準）
- 回転方向指定：正方向・逆方向
- 回転速度指定：0.25～5 rpm（出力軸基準）
- A・Dキーの長押しによる連続回転（ジョグ操作）
- `stop/停止` ボタンおよびESP32のBOOTボタンによる停止・励磁解除
- 回転中のSTEPパルス数、進捗、通信ログの表示
- SPIによるTMC5160の初期設定と異常確認
- RMTによるSTEPパルス生成、加速処理（角度指定時は減速処理も実施）
- USB通信途絶時の自動停止処理

## 2. 使用機材・動作環境

| 項目 | 内容 |
| --- | --- |

| モータ | StepperOnline 23HS32-4004S（NEMA23、4線式、1.8°/step、定格4 A/相） |
| 減速比 | 25:1 |
| モータ電源 | DC 24 V 安定化電源（初期無負荷試験の電流制限：1 A） |

| 開発環境 | ESP-IDF v6.1.1（ファームウェア再書き込み時のみ必要） |

## 4. 配線

### ESP32-S3とTMC5160T Pro

| ESP32-S3 | TMC5160T Pro | 用途 |
| --- | --- | --- |
| 3V3 | VIO | ロジック電源 |
| GND | VIO側 GND | 共通GND |
| GPIO4 | STP (STEP) | ステップパルス |
| GPIO5 | DIR | 回転方向 |
| GPIO6 | EN | ドライバ有効化（LOWで有効） |
| GPIO10 | CFG3 (CS) | SPIチップセレクト |
| GPIO11 | CFG1 (MOSI) | SPIデータ送信 |
| GPIO12 | CFG2 (SCK) | SPIクロック |
| GPIO13 | CFG0 (MISO) | SPIデータ受信 |

- TMCのCLKをGNDに接続する。
- EN（GPIO6と同じ信号線）と3.3 Vの間に10 kΩのプルアップ抵抗を接続する。

### モータ電源とモータ

| 接続元 | 接続先 |
| --- | --- |
| 安定化電源 +24 V | TMC VM |
| 安定化電源 マイナス | TMC VM側 GND |
| モータ 黒 | A1（A+） |
| モータ 緑 | A2（A−） |
| モータ 赤 | B1（B+） |
| モータ 青 | B2（B−） |

モータ線の色は今回のモータを前提としています。接続前にテスターで相の組み合わせ（黒・緑、赤・青）を確認してください。モータ4線は共通GNDに接続しません。

今回の試験構成には外付けのVM-GND間コンデンサを追加していません。電源条件や配線長を変更する場合は、ドライバの推奨電源回路およびサージ対策を確認してください。

**物理ピン位置は実機のシルク印刷・メーカーのピン配置で確認してください。GPIO番号とヘッダの順番は同じではありません。** 

## 5. 使用方法（ファームウェア書き込み済みの場合）

書き込み済みのESP32を使用する場合はこちらの手順だけで操作できます。

### 5.1 PCの準備

Python 3をインストールし、ターミナル（PowerShell等）でGUIを取得したフォルダに移動します。初回のみ必要なライブラリをインストールします。

```powershell
python -m pip install pyserial
```

Tkinterは通常のWindows版Pythonに付属します。必要に応じて `python -m tkinter` で起動を確認してください。

### 5.2 USB通信確認（任意・トラブル時推奨）

24 V電源をOFFのままESP32をUSB接続します。ESP-IDF Monitorや他のシリアル通信ソフトは閉じてください。

```powershell
python usb_check.py COM17
```

`COM17` は開発時の例です。使用するPCで割り当てられたCOM番号に変更してください。

正常応答の例：

```text
Opened COM17
HELLO RMT_GUI_V2
STATE NOT_READY 0 0
PONG
USB OK
```

### 5.3 GUI起動

```powershell
python gui.py
```

1. GUIで「更新」を押し、対象のCOMポートを選択する。
2. 「接続」を押す。
3. モータの配線・固定・無負荷状態を確認し、24 V電源をONにする。
4. 「TMC初期化（24V ON後）」を押す。
5. `READY / 回転可能` の表示を確認する。
6. 角度指定またはジョグ操作を行う。

### 5.4 角度指定による回転

1. 相対角度（1～360°）を入力する。
2. 速度（0.25～5 rpm）を選択または入力する。
3. 正方向・逆方向を選択する。
4. 「回転開始」を押す。

指定パルス数に達すると自動停止し、励磁を解除します。READYに戻れば再度回転できます。角度は絶対位置ではなく、現在位置からの相対移動量です。

最初のテストは **10°・0.5 rpm・無負荷** を推奨します。

### 5.5 キーボードによるジョグ操作（V2）

READY状態で速度を設定し、「キーボード操作を有効にする」にチェックを入れます。日本語入力をOFFにしてください。

| キー・操作 | 動作 |
| --- | --- |
| Dを押し続ける | 設定速度で正転 |
| Aを押し続ける | 設定速度で逆転 |
| キーを離す | 停止・励磁解除 |
| AとDを同時に押す | 停止（両方離してから再操作） |
| ウィンドウからフォーカスが外れる | ジョグ停止 |
| stop/停止 または ESP32のBOOTボタン | 停止・励磁解除 |

- ジョグ操作では相対角度の入力値は使用しません。360°を超えて回転できます。
- 速度はキーを押した時点で決まります。変更する場合はキーを離して停止してから設定してください。
- 入力欄や速度選択欄にフォーカスがあるときは誤操作防止のためジョグを開始しません。設定変更後は「キー操作に戻る」を押してください。
- 角度指定による回転中はジョグを開始できません。
- フォーカス喪失などで操作が解除された場合は、停止を確認してから再度有効化してください。

### 5.6 終了

`stop/停止` を押して動作停止を確認し、「切断」を押します。24 V電源をOFFにしてからGUIを閉じ、必要に応じてUSBを抜いてください。

## 6. 回転制御の仕様

モータは1.8°/stepのため、モータ軸1回転は200フルステップです。16マイクロステップ、減速比25:1のため、出力軸1回転に必要なパルス数は次のとおりです。

```text
200 × 16 × 25 = 80,000 pulses/rev

指令パルス数 = round(80,000 × 指定角度 / 360)
STEP周期 [μs] = round(750 / 出力軸速度 [rpm])
```

| 出力軸回転角度 | 指令パルス数 |
| ---: | ---: |
| 10° | 2,222 |
| 90° | 20,000 |
| 180° | 40,000 |
| 360° | 80,000 |

| 出力軸速度 [rpm] | モータ軸速度 [rpm] | STEP周期 [μs] | 出力軸1回転の定速換算時間 [秒] |
| ---: | ---: | ---: | ---: |
| 0.25 | 6.25 | 3000 | 240 |
| 0.5 | 12.5 | 1500 | 120 |
| 1 | 25 | 750 | 60 |
| 2 | 50 | 375 | 30 |
| 3 | 75 | 250 | 20 |
| 4 | 100 | 188 | 約15 |
| 5 | 125 | 150 | 12 |

速度は定速時の指令値です。加減速、RMTブロック間の処理、SPIによる異常確認などにより実際の所要時間は長くなる場合があります。

本プログラムはエンコーダを使用しないオープンループ制御です。表示されるパルス数は指令・生成したパルス数であり、実際の回転角度を測定した値ではありません。脱調や減速機のバックラッシュは検出・補正できません。

## 7. ファームウェアの再書き込み（開発者向け）

別のESP32を使用する場合、またはファームウェアが上書きされた場合に実施します。

1. 24 V電源をOFFにする。
2. 既存のESP-IDFプロジェクトをバックアップする。
3. V2の `main/main.c` と `main/CMakeLists.txt` を上書きする。
4. ESP-IDF v6.1.1の環境を有効化する。
5. `sdkconfig` で `CONFIG_ESP_CONSOLE_USB_SERIAL_JTAG=y`（primary console）を確認する。
6. 対象ポートを確認し、Build・Flashを実行する。

ESP-IDFターミナルでの実行例：

```powershell
idf.py build
idf.py -p COM17 flash
```

新規プロジェクトを用意する場合はターゲットをESP32-S3に設定してください。`usb_check.py` で `HELLO RMT_GUI_V2` と `PONG` が返ることを確認してからGUIを使用します。

BuildだけではESP32内のファームウェアは変化しません。Flashで別のプログラムを書き込む、またはフラッシュメモリを消去するまでは、電源を切ってもテストプログラムは保持されます。

## 8. 通信仕様（開発者向け）

USB Serial/JTAG上の改行区切りASCIIコマンドを使用します。

| PCからのコマンド | 用途 |
| --- | --- |
| `HELLO` | 通信バージョン確認 |
| `PING` | 接続監視（応答：PONG） |
| `STATUS` | 現在状態の取得 |
| `INIT` | TMC初期化 |
| `MOVE <angle> <period_us> <dir>` | 角度指定回転 |
| `JOG <period_us> <dir>` | 連続回転開始 |
| `JKEEP` | ジョグ継続指令 |
| `STOP` | 停止・励磁解除 |

方向は `0` が正方向、`1` が逆方向です。時計回り・反時計回りの対応はモータの配線や観察方向によります。GUI側はPINGを約0.5秒ごと、ジョグ中はJKEEPを約120 msごとに送信します。

## 9. 安全上の注意

- 配線変更やモータの抜き差しは、USBと24 V電源の両方を切り、放電を確認してから行ってください。
- 24 VをESP32のGPIO、3V3、TMCのVIOに接続しないでください。
- ESP32、TMC、安定化電源のGNDは共通にします。モータ電源・モータ線はブレッドボードを経由させず、適切な定格の配線を使用してください。
- モータを固定し、回転部に手や物が巻き込まれないようにしてください。無負荷・低速で試験を開始してください。
- 高速試験は2、3、4、5 rpmと段階的に上げ、異音・振動・脱調・異常発熱があれば停止してください。
- 通信監視は通常回転で約3秒、ジョグではJKEEPが約650 ms途絶すると停止する設計です。停止判定はRMTブロック間などで行われるため、停止は瞬時ではありません。
- 停止後は励磁解除されるため、保持トルクが失われます。外力や負荷で軸が動く可能性があります。
- GUIの停止ボタン、BOOTボタン、通信監視はハードウェア非常停止の代わりにはなりません。異常時にモータ電源を遮断できるようにしてください。

## 10. トラブルシューティング

| 症状・ログ | 対処 |
| --- | --- |
| COMポートを開けない | ポート番号、USBケーブル、他のシリアルソフトの占有を確認する。 |
| USB FAILED / HELLO・PONGなし | Monitorを閉じ、COM番号、V2ファームウェア、USB接続を確認して `usb_check.py` を再実行する。 |
| ファームウェアのバージョン不一致 | GUIとESP32の両方をV2に統一する。 |
| `ERR SPI_OR_EN` / IOINが00000000 | 24 V電源、VIO、共通GND、SPI配線、ENを確認する。 |
| `STEP/DIR/EN wiring check FAILED` | GPIO4・5・6とSTP・DIR・ENを再確認する。物理ピンの1ピンずれに注意する。 |
| `ERR RESET_REQUIRED` | モータを停止し、電源・配線・異常原因を確認した後、ESP32をリセットして接続・初期化する。 |
| A・Dキーが反応しない | READY、キーボード操作の有効化、日本語入力OFF、「キー操作に戻る」、キーの押し直しを確認する。 |
| 回転開始ボタンが押せない | READY状態、入力範囲、通信状態、ジョグ停止を確認する。 |
| モータが振動するだけ・脱調する | 停止し、電源を切って相配線や負荷を確認する。速度を下げて再試験する。 |
