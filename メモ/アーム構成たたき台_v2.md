# アーム構成 たたき台 v2(2026-11-17)

作成:吉田 / 11/18 打ち合わせ用

> 数値はすべて**仮定にもとづく概算**です。打ち合わせと試験の結果で見直します。
> v1(アーム打ち合わせ資料_1118.md)からの主な変更:**肘のモーターを肩に移してロッドで駆動**、**肘にベルト2:1と絶対値エンコーダを追加**、**リンクを角形アルミフレームに変更**。

---

## 1. 全体の構成

```
[ローバー天板] ── 台(肩の高さ 約0.6m)
   └ ベース回転:NEMA23 + サイクロイド
       └ 肩の土台
           ├ 肩:RobStride RS04 + ガススプリング ── 上腕(関節間 450mm)
           └ 肘の駆動:23HS32 → ベルト2:1 → サイクロイド25:1 → クランク
                                                   └ ロッド ── 肘側のレバー ── 前腕(関節間 400mm)
                                                                              └ 手首ピッチ → 手首回転 → グリッパ
```

| 関節 | アクチュエータ | 置き場所 | 備考 |
|---|---|---|---|
| ベース回転 | NEMA23 + サイクロイド減速機 | 天板の台 | 重力がかからないので小さくてよい |
| 肩 | **RobStride RS04** + ガススプリング | 肩の土台 | 腕の自重をばねで打ち消し、定格40Nm内に収める |
| 肘 | **23HS32 + HTD 5Mベルト2:1 + サイクロイド25:1(合計50:1)** | **肩の土台**(ロッドで肘を駆動) | 出力軸に絶対値エンコーダ(AS5048A) |
| 手首ピッチ | NEMA17 + 減速機 | 前腕の先 | 必要 約6Nm(2kg時) |
| 手首回転 | NEMA17 またはサーボ | 手首 | ノブ・レバー・鍵を回す |
| グリッパ | 平行グリッパ、送りねじ式 | 手先 | 開き12cm以上。電源が切れても物を離さない |
| 手先カメラ | — | 手首 | 操縦用・ArUco位置合わせ用 |

| 関節間:肘〜手首 | 400mm | 同上 |
| 手首〜指先 | 150mm | |

## 3. 肘の駆動(ロッド方式)

| 項目 | 値 |
|---|---|
| モーター | 23HS32-4004S(保持トルク2.4Nm、4A/相、1.2kg) |
| ベルト | HTD 5M、幅15mm、モーター側30歯・減速機側60歯(2:1) |
| ベルトにかかる力 | 約100N(GT2 6mm・20歯だと約375Nで強度不足) |
| 減速機 | 自作サイクロイド 25:1(リングピン26本、アルミ製ディスク25山) |
| 合計減速比 | 50:1 |
| 出力トルク(動作中) | 約47Nm(効率0.65、モーター実用トルク1.44Nm) |
| 出力の速さ | モーター300rpmで肘6rpm(毎秒36°) |
| クランク・肘側のレバー | 同じ長さ(約100mm)で平行四辺形 → 前腕の角度は肘モーターだけで決まる |
| ロッド | 直径10mmのアルミまたは鋼の丸棒 + 両端ロッドエンド |
| ロッドにかかる力 | 約300N(肘30Nm ÷ クランク0.1m) |
| 座屈の余裕(長さ450mm) | アルミΦ10:約5倍 / 鋼Φ10:約16倍 |
| エンコーダ | AS5048A(14bit)を減速機の出力軸に。先端での分解能 約0.3mm |

**注意**
- 静止時は計算上 約78Nm出せてしまう → **試験1で減速機の耐久が分かるまで、ドライバの電流を下げて35〜40Nmに制限**
- 平行リンクは死点があるため、肘の可動範囲は上腕に対して**約±60〜70°**。地面と1.5mに届くか3Dモデルで確認
- エンコーダで「指令角度と実際の角度のずれ」を監視し、脱調したら停止

## 4. 必要トルク(腕を水平に伸ばしきった状態)

**質量の仮定**:リンク1 0.65kg、ロッド 0.3kg、肘の軸受・レバー 0.4kg、リンク2 0.4kg、手首ピッチ 0.8kg、手首回転+グリッパ 1.0kg(肘モーターは肩に移したので腕には含まない)
**必要トルク** = 静的トルク × 1.5

| 荷物 | 肩(静的) | 肩(×1.5) | 肘(静的) | 肘(×1.5) |
|---|---|---|---|---|
| 0kg | 22 Nm | 34 Nm | 9 Nm | 13 Nm |
| 2kg | 42 Nm | 63 Nm | 20 Nm | 29 Nm |
| 5kg | 72 Nm | 107 Nm | 36 Nm | 54 Nm |

**v1からの改善**:肘モーターを肩に移したことで、肩の必要トルクが2kg時 72Nm → **63Nm**に低下。

### 肩:ガススプリングで自重を打ち消した場合

| 条件 | 肩のモーターが受け持つトルク(×1.5) | RS04定格40Nmとの比較 |
|---|---|---|
| 2kgを先端(1.0m)で保持 | 約29Nm | ○ 定格内 |
| 5kgを肩から0.5m以内で保持 | 約37Nm | ○ 定格内(余裕は小さい) |

※ RS04の定格40Nmは345×345mmアルミヒートシンク条件。220×200mmでは35Nm。

### 肘
| 条件 | 必要(×1.5) | 出力(動作中) | 判定 |
|---|---|---|---|
| 2kg | 29Nm | 約47Nm | ○ 余裕 約1.6倍 |
| 5kg(先端) | 54Nm | 約47Nm | × → 5kgは体の近くで扱う |

## 5. 質量の見積もり

| 部分 | 質量 |
|---|---|
| 動く腕(リンク・ロッド・肘・手首・グリッパ) | 約3.6kg |
| 肩の土台(RS04 1.42kg、23HS32 1.2kg、減速機 約0.6kg、ベルト・プーリー 約0.3kg) | 約3.5kg |
| ベース回転(NEMA23+減速機)と台・金具 | 約2.8kg |
| **合計** | **約10kg** |

→ **v1で仮置きした上限8kgを超える見込み。** 打ち合わせで、アームに使える質量の上限を決める必要あり。
(機体全体35kg以内でTRCの得点倍率2.0。35kgを超えると1.5に下がる)

## 6. 試験(11/22まで)

| # | 試験 | 方法 | 判断に使うこと |
|---|---|---|---|
| 1 | 減速機のトルク | 出力軸に20cmの腕+吊りはかり。30〜40Nmまで段階的に | 減速機を使い続けるか、電流制限値 |
| 2 | 電源を切ったときの逆回転 | 2kg相当を水平保持して電源OFF | ブレーキ・ばねの要否(非常停止対策) |
| 3 | ベルトの歯飛び | 2kg相当を持たせて動かす | ベルト幅・張りの調整 |
| 4 | フレームの質量 | 手元のフレームを計量 | 質量見積もりの更新 |
