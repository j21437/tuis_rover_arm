## アームに必要な機能

### ① 押す(TRCの必須タスク・最優先)  

- Task1-1.2:着陸機の押しボタン(高さ約50cm)【Expert必須】
- Task4-4.2:観測装置のボタン(高さ約40cm)【Expert必須】  
- (URC)ボタン・スイッチ・ノブの操作  

### ② 掴んで運び、箱に入れる(TRCの得点の中心)

| 対象 | 大きさ・重さ | 入れる先 | 区分 |
| --- | --- | --- | --- |
| 岩石(Task2-2.3) | 岩1個 | 収納ボックス(約26×37×16cm) | 実質必須・配点大 |
| キューブ | 7cm角・200g以下 | 資材収納箱(内寸70×40×30cm) | 必須 |
| レンガ | 21×10×6cm・約2kg | 同上 | 必須(重いほど高得点) |
| 金属球 | 直径11.2cm・約5kg | 同上 | 同上 |
| 棒 | 直径4〜5cm×50〜100cm・1〜3kg | 同上 | 同上 |
| レンガ積み | レンガ3個を積む(最大2山) | 積み上げスペース | Expertのみ・配点大/山 |
| (URC)物資・キャッシュ | 5kg未満、つかむ部分の直径≦7.5cm | 指定の場所・引き出し | --- |
| (URC)ハンマー | ロックピックハンマー | 自律で拾う・置く | 10点+5点 |

### ③ 細かい操作(TRCは任意だが配点大、URCでは中心)

- TRC:トグルスイッチ(1.3)、プラグを抜く(1.4)、アンテナのポールを引き出す(4.3)。いずれも配点「large」
- URC:キーボードの自律入力、鍵を抜いて別の鍵穴に挿して回す、引き出しの開閉、ラッチを外してパネルを開く、ホースの差し込み接続、1/4回転レバー、試験管をキャッシュに入れてロック  

## 機能　→　仕様  

| 項目 | 目安 | 根拠 |
| --- | --- | --- |
| 持ち上げる重さ | 2kg(第1段階) → 5kg(最終) | レンガ2kg、金属球・URCの物資5kg |
| 届く範囲 | 地面〜高さ1.5m | 地面から拾う、ボタン40〜50cm、URCの機器は0〜1.5m |
| つかめる幅 | 12cm以上 | 金属球の直径11.2cm |
| 手首 | 回転軸が必要 | ノブ・レバー・鍵を回す、棒の向きを合わせる |
| 精度 | 第1段階は数cm、URCでは±数mm | ボタンは粗くてよい。キーボード・鍵穴は細かい |
| カメラ | 手先カメラが必要 | 操縦者は機体を直接見られない。URCではArUcoで位置合わせ |
| 重さの上限 | 機体全体35kgの中で配分を決める | TRCでは20〜35kgで得点倍率2.0、35kgを超えると1.5に下がる |
| 収納時の大きさ | 機体全体で各辺1.2m以下 | TRC・URC共通 |
| 非常停止したとき | 物を落としても危なくないか、姿勢を保てるか | 非常停止は全電源を遮断するため |
| 環境 | 防水・防砂 | TRCは雨でも開催、URCは砂ぼこり |
