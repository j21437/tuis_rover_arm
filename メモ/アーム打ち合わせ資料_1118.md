### URC2027

| ミッション | アームの動作 |
|---|---|
| Equipment Servicing | 機器は**地面〜高さ1.5m**。キーボード自律入力(ArUco 2cm)、鍵の抜き差し・回転、引き出し開閉、ラッチ・パネル、ホース接続(1.5インチ カムロック)、1/4回転レバー、ボタン・スイッチ・ノブ、試験管をキャッシュに挿入しロック、キャッシュ(5kg未満、ハンドル径5cm以下)の運搬 |

### 共通の機体要求
- 収納時に 1.2m × 1.2m × 1.2m 以内(TRC:各辺1,200mm以下)
- 非常停止で全電源を遮断(→ 電源が切れても腕・荷物が落ちない対策が必要)
- 防水・防砂(TRCは雨天でも屋外開催、URCは砂ぼこり・高温)
- 機体全体の目標:**35kg以内**(TRCの得点倍率 20〜35kg:2.0 / 35〜50kg:1.5)

## 4. 腕の長さ(URCの高さ1.5mから逆算)

**前提**:肩〜機体前端 15cm、機体前端〜ランダー面 15cm、手首中心〜指先 15cm、腕は最大長の95%まで使用

| 肩の高さ(地面から) | 1.5mを水平に押す | 1.5mを斜め45°上向きに押す | 地面の物(真上から) |
|---|---|---|---|
| 0.4m | 1.17m | 1.07m | 0.49m |
| 0.5m | 1.06m | 0.96m | 0.54m |
| **0.6m** | 0.96m | **0.86m** | 0.60m |
| 0.7m | 0.86m | 0.76m | 0.67m |

(数値は必要な関節間距離の合計「肩〜肘+肘〜手首」)

**たたき台**:肩の高さ 0.6m前後、高い位置は斜め45°上向きで操作
- 関節間:肩〜肘 **450mm**、肘〜手首 **400mm**
- パイプ(G-funフレームN)を切る長さの目安:約 **380mm** / 約 **350mm**(金具の寸法による)
- 注意:肩を高くすると重心が上がる → 走行中は腕を低くたたむ

## 6. アクチュエータの能力

### 肩候補:RobStride 04(RS04)

| 項目 | 値 |
|---|---|
| 定格トルク | 40 Nm(345×345mmアルミヒートシンク条件。220×200mmでは35 Nm) |
| ピークトルク | 120 Nm(短時間のみ) |
| 減速比 | 9:1 |
| 質量 | 1420g ± 20g |
| 電圧 | 48V(定格) |

→ 腕の自重だけで約43Nm必要なため、**定格内に収めるにはガススプリング等で自重を打ち消す必要がある**。
自重を打ち消せば、2kg先端保持で約28Nm、5kgを肩から0.5m以内で約37Nm(いずれも定格内)。

### 肘候補:23HS32-4004S + 自作サイクロイド減速機

| 項目 | 値 |
|---|---|
| モーター保持トルク | 2.4 Nm |
| 定格電流 | 4.0 A/相(ドライバも4A対応が必要) |
| インダクタンス | 3.2 mH |
| モーター質量 | 1.2 kg |
| 減速比 | 25:1(リングピン26本、ディスク25山、アルミ製ディスク) |
| 許容トルク・効率・バックラッシュ | **未評価** |

| 構成 | 出力トルク(静止時) | 出力トルク(動作時・保持トルクの60%) |
|---|---|---|
| 減速機のみ 25:1(効率65%) | 39 Nm | 23 Nm |
| ベルト2:1 + 減速機 = 50:1 | — | 約47 Nm |

→ たたき台の長さでは、2kgでも肘に約30Nm必要 → **ベルトで1段減速を足す案を推奨**
→ モーターを肩側に置けば、肩の負担も静的に約4.5Nm減る
→ 24V前後の電源では200〜300rpm付近からトルクが低下(概算)。300rpm×50:1で肘は6rpm(毎秒36°)

## 7. 構成のたたき台

| 関節 | アクチュエータ案 | 備考 |
|---|---|---|
| ベース回転 | NEMA23 + サイクロイド | 重力負荷が小さい |
| 肩 | RS04 + ガススプリング | 自重をばねで打ち消す |
| 肘 | 23HS32 + サイクロイド25:1 + ベルト2:1 | モーターは肩側に配置 |
| 手首ピッチ | NEMA17 + 減速機 | 必要 約6Nm(2kg時) |
| 手首回転 | NEMA17 またはサーボ | |
| グリッパ | 平行グリッパ、送りねじ式、開き12cm以上 | 電源が切れても物を離さない |
| リンク | G-funフレームN | 関節との接続は**ボルト・ピン貫通で滑り止め**(摩擦固定だけにしない)。剛性が必要なら2本平行 |

### G-funフレームN(28mm)の確認結果
- 断面2次モーメント:Ix = Iy = 1.16×10⁴ mm⁴
- 肩の付け根の曲げ応力:2kgで約56MPa(アルミ降伏点 約145MPaに対し約2.6倍)、5kgで約90MPa(約1.6倍)
- たわみ:2kg・腕を伸ばした状態で、先端が約1cm下がる見込み(パイプ1本の場合)
